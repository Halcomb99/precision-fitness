# Precision Fitness

Workouts and meal plans built around your goals. A mobile web app that installs to your home screen and works offline.

- Discovery: ideal body, experience, portion size, eating style, foods you love and avoid
- Calendar: plan a day, then pick muscle groups, location and time to get a workout
- Set logging with weight/rep suggestions and personal records
- Daily meal plans with hand-portion sizing

Exercise illustrations and data by [RepDB (repdb.co)](https://repdb.co).
